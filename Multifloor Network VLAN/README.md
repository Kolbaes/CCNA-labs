## Multi-Floor VLAN Network

## Topology:
  - 1 Router
  - 1 Core Switch
  - 3 Access Switches
  - 6 PC's
  - 3 VLAN's
    - HR
    - Admin
    - IT

## Configuration
  - VLAN configuration on access switches
  - Inter-VLAN routing using Router-on-a-Stick
  - Tested with DHCP IP addressing


## Skills Used
  - VLAN's
  - DHCP IP addressing
  - Trunk (802.1Q)
