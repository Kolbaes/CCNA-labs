### Topology
  - 2 Routers (Router-to-Router WAN link)
  - 2 Switches
  - 4 PC's (2 for each LAN)

### Network Design
  - Implemented VLSM to subnet a /24 network into multiple /28 LANs
  - Used /30 subnet for point-to-point WAN communication

### Configuration
  - Assigned IP addressing for LAN 1, LAN 2, WAN
  - Configured router interfaces and default gateways on end devices
  - Implemented static routing b/w router to enable inter-LAN connectivity

### Verification
- Verified connectivity using ICMP (ping) between:
  - PCs within the same LAN
  - PCs across different LANs via the WAN link

### Skills Used
  - VLSM (Variable Length Subnet Masking)
  - Router-to-Router Point-to-Point Networking
  - Static Routing
